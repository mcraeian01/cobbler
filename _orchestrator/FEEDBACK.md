# Feedback for agents

The owner writes here. The orchestrator relays each item in the topic's next wake message, then marks it relayed. Reply to a digest with feedback and it can be added here for you.

Write it however you like. Praise, redirection and "stop doing X" all work.

```
## <topic>
- <feedback> (added YYYY-MM-DD)
- <feedback> (added YYYY-MM-DD, relayed YYYY-MM-DD)
```

Feedback for a topic that is not woken stays pending until it is. If something should go out right away, also raise that topic's priority or leave a note in its STATE.md.
